Privacy policy

Last updated: November 22, 2026

market-updates is a personal tool used only by its owner, Brick by Brick Trades. It does not collect, store, sell or share personal information about any other person.

What the app accesses

With the owner's permission, the app uses the YouTube upload permission to upload the owner's own videos, with a title and description, to the owner's own YouTube channel. It does not read the owner's subscribers, comments, watch history or any other account data.

How the login is stored

The Google authorization token is kept in the owner's private GitHub secret storage and is used only for the uploads described above. It is not shared with anyone.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
